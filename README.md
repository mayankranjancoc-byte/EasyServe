# 📱 EasyServe - Smart Billing Assistant
> **Offline-First Mobile Billing App for Small Businesses**

![Status](https://img.shields.io/badge/Status-Demo%20Ready-success) ![Offline](https://img.shields.io/badge/Offline-100%25-blue)

EasyServe is a production-ready billing app that helps small shop owners digitize operations without internet. It replaces paper billing with a fast, intuitive mobile interface.

## ✨ Key Features
- **🛒 One-Tap Billing**: Instant item addition from a catalog of 150+ realistic items.
- **📸 OCR Bill Scanning**: Digitizes handwritten bills with confidence scores.
- **📦 Auto-Inventory**: Stock updates automatically with every sale and history logging.
- **💰 Payment Tracking**: Manage paid vs. pending bills with visual indicators.
- **📥 Bulk Export**: Filter and download bills as CSV (Date/Payment Method support).
- **🎤 Voice Assistant**: "Create bill for 2 milk", "Check stock of sugar", "Show sales".
- **📴 100% Offline**: Zero dependencies, single HTML file architecture.

## 🚀 Quick Start
1. **Open `index.html`** in any browser (Chrome recommended).
2. **Switch to Mobile View** (F12 → Device Toolbar → Select iPhone/Pixel).
3. **Explore**:
   - App auto-generates **300+ past bills** and **150+ items**.
   - Try the **Voice Assistant** (microphone icon).
   - Use **Scan Bill** to simulate OCR.
   - Click **Export** on the home screen to download reports.

## 🛠️ Tech Stack
- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Storage**: LocalStorage (Offline Persistence)
- **Deployment**: Single-file PWA ready
- **No External Dependencies**

## 🎬 Demo Highlights
1. **Dashboard**: View daily sales, low stock alerts, and recent bills.
2. **Billing**: Search "milk", add quantity, apply discount, checkout.
3. **Voice**: Ask "Show today's sales" or "List low stock items".
